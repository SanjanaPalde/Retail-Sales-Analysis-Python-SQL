# 🗄️ SQL Analysis

SQL queries were created to answer important business questions.

### 💰 Total Revenue

Calculates the total revenue generated from all sales.

```sql
SELECT SUM(Total_Amount) AS Total_Revenue
FROM sales;
```

### 🏷️ Revenue by Category

Determines revenue generated by each product category.

```sql
SELECT Category,
       SUM(Total_Amount) AS Total_Revenue
FROM sales
GROUP BY Category
ORDER BY Total_Revenue DESC;
```

### 🏙️ Revenue by City

Ranks cities according to total revenue.

```sql
SELECT City,
       SUM(Total_Amount) AS Total_Revenue
FROM sales
GROUP BY City
ORDER BY Total_Revenue DESC;
```

### 💳 Payment Method Analysis

Identifies the most-used payment methods by counting orders for each payment method.

### 📦 Top Selling Products

Products are analyzed using both:

* Total quantity sold
* Total revenue generated

The SQL analysis groups sales by `Product_Name` and sorts the results to identify the highest-performing products.

### 📅 Monthly Revenue

Monthly revenue is calculated by extracting the month from `Order_Date` and summing `Total_Amount`.
